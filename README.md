# Акт за вечер

Узкий платный инструмент. Самозанятый заполняет условия одной сделки и получает три документа: договор возмездного оказания услуг, акт сдачи-приёмки и счёт на оплату. Цена пакета — **690 ₽**. Это не подписка и не работа юриста.

Покупатель — самозанятый, которому заказчик не переводит деньги, пока не увидит заполненные договор и акт. Пустые комплекты таких форм уже продаются за 1 490–1 990 ₽. Разовый пакет, который юрист собирает по переписке, стоит от 1 490 ₽. Здесь результат в тот же вечер и без переписки: человек сам вносит данные и сам читает текст перед подписанием.

Сервис не требует ручных продаж. Оплата идёт через ЮKassa на магазин самозанятого. Пока ключей нет, сайт работает в тестовом режиме и не проводит оплату.

## Запуск на своём компьютере

Нужен Node.js 20 или новее. Отдельных библиотек нет.

```bash
npm test
npm start
```

Сайт откроется на http://localhost:3000 . Жёлтая плашка «Тестовый режим» означает: платёж не создаётся, деньги не списываются, заказ не становится оплаченным, в журнал не попадает выручка.

Каталог `data/` в git не входит. Там лежат заказы и журнал. Его нельзя коммитить: в заказах имена и ИНН.

## Как подключить оплату на счёт самозанятого

1. Статус НПД уже должен быть в «Мой налог». Магазин заводит сам самозанятый.
2. Подайте заявку на ЮKassa для самозанятых: https://yookassa.ru/platezhi-dlya-samozanyatyh/ . По опубликованным условиям абонентской платы нет, комиссия только с успешного платежа. Платить могут физические лица.
3. В личном кабинете возьмите `shopId` и секретный ключ **боевого** магазина. Ключи тестового магазина для запуска не подходят: такой платёж этот сайт не считает продажей.
4. Скопируйте `.env.example` в `.env`. Файл `.env` в git не попадает.
5. Заполните переменные:
   - `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`
   - `PUBLIC_BASE_URL` — публичный адрес с https, без слэша в конце
   - `OPERATOR_NAME` — ФИО получателя
   - `OPERATOR_INN` — ИНН самозанятого, 12 цифр
   - `OPERATOR_EMAIL` — почта, её видно покупателю
   - `LEDGER_TOKEN` — случайная строка от 16 знаков, ей открывается журнал
   - `YOOKASSA_LIVE=yes` — только в день, когда страница уже открыта покупателям
   - `LAUNCHED_AT` — эта дата в формате `ГГГГ-ММ-ДД`. Если оставить пустым, возьмётся день первого запроса к сайту после `YOOKASSA_LIVE=yes`
6. В кабинете ЮKassa укажите HTTP-уведомления на `https://<ваш-адрес>/yookassa/webhook`.
7. Перезапустите процесс. Жёлтой плашки больше нет. Заказ становится оплаченным только если ЮKassa вернула `succeeded`, `paid: true`, `test: false` и ту же сумму.

Ключи остаются только в переменных окружения.

После каждой боевой оплаты получатель сам создаёт чек в «Мой налог» на полную сумму 690 ₽. С 29 декабря 2025 года ЮKassa не передаёт чеки самозанятых, это прямо сказано в её документации. Для безнала срок — не позднее 9-го числа следующего месяца (часть 3 статьи 14 закона № 422-ФЗ). Сумма и дата лежат в журнале: `/ledger?token=...`.

Сайт — один процесс Node.js и файлы в `data/`. Хостинг должен быть бесплатным и хранить этот каталог. Рекламу не покупать. Капитал на этот запуск не тратится.

Если ключи заданы, но `YOOKASSA_LIVE` не равен `yes`, это пробное подключение. Боевой ответ ЮKassa (`test: false`) всё равно выдаёт файлы и пишет журнал: деньги нельзя принять и спрятать. Тестовый ответ продажей не считается, и шесть недель от него не начинаются.

## Журнал

В тестовом режиме `/ledger` открыт и показывает нули. Когда ключи заданы, без `LEDGER_TOKEN` журнал закрыт.

По каждой боевой оплате четыре слоя: выручка, комиссия, налог, чистыми. Рядом с комиссией отдельно виден НДС на неё.

- Выручка — полная цена 690 ₽.
- Комиссия — оценка для банковской карты, 3,5%. С 1 января 2026 года на комиссию по картам и SberPay добавляется НДС 22% от суммы комиссии, не от платежа. Для ЮMoney и T-Pay этого НДС по таблице ЮKassa нет, удержание будет меньше. Точная комиссия — в реестре ЮKassa.
- Налог — 4% с полной выручки. Магазин самозанятого принимает оплату от физического лица. Комиссия базу НПД не уменьшает. К уплате та сумма, которую начислит «Мой налог».
- Чистыми = выручка − комиссия − НДС на комиссию − налог.

На 690 ₽ оценка для карты: комиссия 24,15 ₽, НДС на неё 5,31 ₽, налог 27,60 ₽, чистыми 632,94 ₽.

Тестовые заходы, тестовые платежи ЮKassa и отменённые платежи в суммы не входят.

## Правило остановки

Часы запускаются в дату `LAUNCHED_AT`, когда заданы боевые ключи, публичный https и `YOOKASSA_LIVE=yes`. Дата пишется в `data/launch.json` и не сдвигается вперёд, если переменную потом поменять. Если боевая оплата пришла раньше этой даты, часы начинаются с дня оплаты.

Шесть недель — это 42 дня. Если за 6 недель с запуска нет ни одной боевой оплаты, тему закрываем и капитал не докладываем. Дата запуска — день 0. Правило срабатывает в календарный день через 42 дня, по Москве, если в журнале нет ни одной боевой оплаты.

Пример. Дата запуска 13 ноября. Дни с 13 ноября по 24 декабря включительно есть на первую оплату. Утро 25 декабря без ни одной боевой оплаты — стоп.

Стоп значит:

- новые оплаты не принимаются;
- продукт не дорабатывается;
- рекламу не включать;
- лимит запуска 15–20 тыс. ₽ не тратить;
- капитал 100–150 тыс. ₽ не докладывать.

Уже выданные файлы по прошедшим оплатам остаются по своим ссылкам. Новых затрат нет.

Боевая оплата — платёж ЮKassa со статусом `succeeded`, не тестовый, на сумму заказа. Всё остальное продажей не считается. Пока такой оплаты нет, реклама запрещена, даже если 42 дня ещё не вышли.

Если боевая оплата случилась внутри 42 дней, тему по этому правилу не закрываем. Дальше считать доход чистыми, после комиссии и налога. Капитал по-прежнему не тратить. Решение о рекламе внутри лимита 15–20 тыс. ₽ — отдельное и только после этой оплаты.

## Что сайт не делает

- Не является юристом и не проверяет сделку.
- Не проверяет статус НПД. Это делается на https://npd.nalog.ru .
- Не оформляет трудовой договор и отклоняет описание, похожее на штатную должность.
- Не отправляет чек в «Мой налог».
- Не притворяется оплатой без ключей и не пишет тестовый платёж в выручку.
- Не обещает первую продажу. Её нет, пока живой покупатель не проведёт боевой платёж.
